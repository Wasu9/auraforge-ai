# AuraForge AI — Advanced Free AI Studio

Modern free AI Image Generator + Character Swap guidance.

## Features

- **Advanced Image Generator**
  - Multiple models (FLUX, GPT Image, SDXL)
  - Aspect ratio options
  - 1 / 2 / 4 images at once
  - Surprise Me prompts
  - Quick style chips
  - Local gallery (browser storage)
  - Lightbox view + download

- **Character Swap section** with clear options
- **Local Tools guide** (FaceFusion, Viggle-Animate, Pinokio)

- Fully static → ready for GitHub Pages
- No API key required from you (Puter.js User-Pays model)

## Deploy to GitHub Pages

1. Create a new public repository
2. Upload all files
3. Settings → Pages → Deploy from branch → main / root
4. Live at: `https://your-username.github.io/repo-name/`

## Notes

- First generation may show Puter consent dialog → click Continue
- Gallery is stored in browser localStorage (max 30 images)
- Always use face/character swap tools responsibly
