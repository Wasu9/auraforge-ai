# AuraForge AI

Free AI Image Generator + Character Swap tools website.

## Features

- **AI Image Generation** — Works free via Puter.js (no API key needed from you)
- **Character Swap section** — Clear options for browser face swap + local high-quality tools
- **Local Tools Guide** — FaceFusion and advanced character swap recommendations
- Fully static — ready for GitHub Pages

## How to host on GitHub Pages (free)

1. Create a new repository on GitHub (example name: `auraforge-ai`)
2. Upload all files from this folder (`index.html`, `style.css`, `script.js`, `README.md`)
3. Go to **Settings → Pages**
4. Under "Source" choose **Deploy from a branch**
5. Select branch `main` (or `master`) and folder `/ (root)`
6. Save

After 1-2 minutes your site will be live at:
`https://your-username.github.io/auraforge-ai/`

## Local testing

Just open `index.html` in a modern browser (Chrome / Edge recommended).

## Notes

- First time generating an image, Puter may show a quick anonymous consent dialog. Click **Continue**.
- Character / full body swap of high quality still requires local GPU tools (see the Local Tools section on the site).
- Always use face & character swap tools responsibly and with consent.
